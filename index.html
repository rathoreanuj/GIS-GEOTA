About This Project

Project Title

Spatio-Temporal Analysis and Forecasting of Lake Shrinkage — Hussain Sagar, Hyderabad

Objective

Analyze the historical shrinkage of Hussain Sagar Lake using multi-temporal remote sensing data and forecast future lake area using regression modelling.

Data Sources

Landsat 5/8 (USGS), Sentinel-2 (Copernicus), SRTM DEM, CHIRPS Rainfall, VIIRS Night-Time Light, ESA WorldCover LULC

Tools & Stack

Leaflet.js, Chart.js, HTML5/CSS3/JS — Spatial analyses via Google Earth Engine + Python (GeoPandas, Rasterio)
